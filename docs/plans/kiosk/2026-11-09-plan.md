# 1. Context

**Problem:**
Trạm Kiosk cảm ứng POS tại quầy thu ngân cần phân hệ backend xử lý tự phục vụ: nhận diện SĐT, tích điểm nhanh vào sổ cái kép `points_ledger` khi khách thanh toán POS ngoài, đặt đơn trực tiếp kèm in phiếu & cấp số thứ tự `#A-08`, tự động reset phiên làm việc khi idle quá 60s, và giám sát tình trạng phần cứng (heartbeat, máy in, đầu đọc thẻ).

**Affected Modules:**
- `com.ordera.modules.kiosk` — Module Clean Architecture mới hoàn chỉnh
- `com.ordera.common.util` — Bổ sung `KioskQueueUtils` sinh số thứ tự `#A-08`
- `com.ordera.config` — Cấu hình `SecurityConfig` cho phép route public Kiosk (`/api/v1/kiosk/**`)
- `com.ordera.modules.ledger` & `loyalty` — Tái sử dụng `AccruePointsUseCase` và `TransactionType.KIOSK_EARN`
- `resources/db/migration` — Bổ sung migration `V11__create_kiosk_devices.sql`

**Non-Goals:**
- Tích hợp driver SDK phần cứng máy in ESC/POS vật lý (sử dụng Adapter mô phỏng `ThermalPrinterAdapter`)
- Tích hợp cổng thanh toán trực tiếp BankAxept/Vipps Kiosk (sử dụng giả lập CardReader status ONLINE)

# 2. Constraints

**Language:** Java 21 LTS, Spring Boot 3.3.5
**Architecture:** Clean Architecture 4 Lớp (Domain -> Application -> Infrastructure -> Presentation)

**Rules:**
- Tuân thủ Multi-Tenant Isolation tuyệt đối (Header `X-Tenant-ID` và `TenantContextHolder`)
- Sổ cái điểm kép bất biến: cấm cập nhật trực tiếp điểm số, mọi biến động đều ghi vào `points_ledger`
- Cấm tuyệt đối magic numbers/strings: toàn bộ hằng số gom về `KioskConstants` và `KioskMessages`
- Mã lỗi chuẩn hóa qua `KioskErrorCode` implement `ErrorCode`, ném qua `BusinessException`
- Orchestrator Pattern: hàm `execute()` tối đa 30-40 dòng, Guard clauses, nesting depth <= 3

**Performance Budgets:**
- Kiosk Identify by Phone: < 100ms (p99)
- Kiosk Quick Earn & Print Dispatch: < 200ms (p99)
- Kiosk Session Reset: < 50ms (p99)

# 3. Conventions

**Naming:**
- Classes: `PascalCase` — ví dụ: `KioskQuickEarnUseCaseImpl`, `RedisKioskSessionAdapter`
- Methods/Variables: `camelCase` — ví dụ: `validateKioskDevice()`, `queueNumber`
- Constants: `UPPER_SNAKE_CASE` — ví dụ: `WATCHDOG_IDLE_TIMEOUT_SECONDS`
- Packages: `com.ordera.modules.kiosk.*`

**Error Handling:**
- Luôn ném `BusinessException(KioskErrorCode.<CODE>)`
- Cấm tạo Exception classes riêng lẻ
- Null-safety: `Objects.requireNonNull(arg, "name must not be null")`

**Logging:**
- Sử dụng `@Slf4j` với structured logging: `log.info("Kiosk device {} identified customer phone={}", deviceCode, maskedPhone)`

**Testing:**
- Framework: JUnit 5 + Mockito
- Naming: `should_<expected>_when_<condition>()`
- 100% pass unit tests

# 4. Contracts

## 4.1. Domain Constants & Errors
- `KioskConstants`:
  + `WATCHDOG_IDLE_TIMEOUT_SECONDS = 60`
  + `POST_PAYMENT_REDIRECT_SECONDS = 5`
  + `QUEUE_NUMBER_FORMAT = "#A-%02d"`
  + `PHONE_REGEX = "^(\\+47)?[49]\\d{7}$"`
  + `LOCK_KEY_KIOSK_PATTERN = "lock:kiosk:device:%s"`
  + `SESSION_CACHE_TTL_MINUTES = 30`
- `KioskErrorCode`:
  + `INVALID_PHONE_NUMBER` (400)
  + `KIOSK_DEVICE_NOT_FOUND` (404)
  + `INVALID_STAFF_PIN` (401)
  + `KIOSK_SESSION_EXPIRED` (400)
  + `INVALID_BILL_AMOUNT` (422)

## 4.2. Use Cases Interfaces
- `KioskIdentifyCustomerUseCase.execute(UUID tenantId, String deviceId, KioskIdentifyRequest request): KioskCustomerInfoResponse`
- `KioskQuickEarnUseCase.execute(UUID tenantId, String deviceId, String staffPin, KioskQuickEarnRequest request): KioskQuickEarnResponse`
- `CreateKioskOrderUseCase.execute(UUID tenantId, String deviceId, KioskCheckoutRequest request): KioskCheckoutResponse`
- `ResetKioskSessionUseCase.execute(UUID tenantId, String deviceId, KioskResetSessionRequest request): KioskResetSessionResponse`
- `GetKioskConfigUseCase.execute(UUID tenantId, String deviceId): KioskConfigResponse`

## 4.3. Infrastructure Adapters
- `RedisKioskSessionAdapter`:
  + `saveSession(UUID tenantId, String deviceId, KioskSession session): void`
  + `getSession(UUID tenantId, String deviceId): Optional<KioskSession>`
  + `clearSession(UUID tenantId, String deviceId): void`
- `ThermalPrinterAdapter`:
  + `printQueueTicket(UUID storeId, String queueNumber, String orderCode): boolean`
  + `printReceipt(UUID storeId, String queueNumber, String receiptRef, BigDecimal amount, int pointsEarned): boolean`

# 9. Edge Cases

| Edge Case | Handled In | Behavior |
|---|---|---|
| Phone number not matching Norwegian/international regex | Task 8 (`KioskIdentifyCustomerUseCaseImpl`) | Throw `KioskErrorCode.INVALID_PHONE_NUMBER` |
| Phone number not found in system | Task 8 (`KioskIdentifyCustomerUseCaseImpl`) | Return `isRegistered = false` (allows guest skip) |
| Kiosk deviceCode not found in DB | Task 8 (`GetKioskConfigUseCaseImpl`, `KioskQuickEarnUseCaseImpl`) | Throw `KioskErrorCode.KIOSK_DEVICE_NOT_FOUND` |
| Invalid staff PIN when required | Task 8 (`KioskQuickEarnUseCaseImpl`) | Throw `KioskErrorCode.INVALID_STAFF_PIN` |
| Bill amount < 1.00 NOK | Task 8 (`KioskQuickEarnUseCaseImpl`) | Throw `KioskErrorCode.INVALID_BILL_AMOUNT` |
| Missing X-Tenant-ID header | Task 9 (`KioskController`) | Spring MVC / Filter triggers 400 Bad Request |
| Concurrent quick earn on same member | Task 8 (`KioskQuickEarnUseCaseImpl`) | Handled via Redisson Lock in `AccruePointsUseCase` |

# 10. Risks & Mitigation

| Risk | Impact | Mitigation |
|---|---|---|
| Collision of queue numbers across stores | Low | Store-specific atomic prefix in `KioskQueueUtils` |
| Race condition during session reset and checkout | Medium | Redisson device lock pattern `lock:kiosk:device:{code}` |
| Legacy `kiosk_devices` table conflict in Flyway | Low | Idempotent `CREATE TABLE IF NOT EXISTS` in V11 |
