# 1. Context

**Problem:**  
Ordera là nền tảng quản trị khách hàng thân thiết và đặt món đa thương hiệu (Multi-Tenant). Hiện tại backend đã có tầng migration và một số Entity JPA thô, nhưng chưa có các lớp Domain thuần túy, 7 Use Cases độc lập, Repositories hoàn chỉnh, DTOs và REST Controllers đáp ứng 7 API nghiệp vụ theo tài liệu kiến trúc Clean Architecture 4 lớp.

**Affected Modules:**  
- `com.ordera.modules.tenant` — Triển khai trọn vẹn 4 tầng (Domain, Application, Infrastructure, Presentation) cho Tenant, Store, Table, Favorite Store, Kiosk Device.
- `com.ordera.common.exception` — Mở rộng `GlobalExceptionHandler` để xử lý các mã lỗi RFC 7807 (`TENANT_HEADER_MISSING`, `STORE_NOT_FOUND`, `INVALID_QR_TOKEN`, etc.).
- `com.ordera.config` — Cập nhật `SecurityConfig` cho phép các endpoint public của `/api/v1/tenants/**` và `/api/v1/stores/**`.

**Non-Goals:**  
- Không triển khai module Catalog (Menu món ăn, danh mục) trong kế hoạch này (thuộc phân hệ Catalog).
- Không triển khai module Order & Checkout trong kế hoạch này (thuộc phân hệ Order).
- Không sửa đổi database migration schema đã có (V1, V2, V9, V10 đã đầy đủ các bảng và RLS).

---

# 2. Constraints

**Language & Framework:** Java 21 LTS, Spring Boot 3.3.5, Spring Data JPA, MapStruct, Lombok.  
**Architecture:** Clean Architecture 4 lớp (Presentation ➜ Application ➜ Domain ➜ Infrastructure).  

**Rules:**  
- Tầng Domain tuyệt đối độc lập với Spring Framework và JPA (Pure Java POJOs & Exceptions).
- Mọi Use Case thực thi trong transaction `@Transactional(readOnly = true)`.
- Mọi truy vấn database nghiệp vụ đều phải lọc theo `TenantContext.getTenantId()`.
- Mọi API response đều được bọc trong `ApiResponse<T>` chuẩn hóa.

---

# 3. Conventions

**Naming:**  
- Domain Models: `Tenant`, `Store`, `StoreTable`, `CustomerFavoriteStore`, `KioskDevice`.
- Use Cases: `<Action>UseCase` interface và `<Action>UseCaseImpl` class.
- Repositories: `<Entity>Repository` kế thừa `JpaRepository`.
- Controllers: `TenantController`, `StoreController`.
- Tests: `should_<expected>_when_<condition>()`.

**Error Handling:**  
- Domain Exceptions: `StoreNotFoundException`, `TableNotFoundException`, `InvalidQrTokenException`, `TenantNotFoundException`, `TenantHeaderMissingException`.
- Xử lý lỗi tập trung tại `GlobalExceptionHandler` trả về mã lỗi RFC 7807 và HTTP status code tương ứng (400, 401, 404).

# 4. Contracts

## Interface: `GetTenantInfoUseCase`
```java
TenantResponse execute();
// pre: TenantContext.getTenantId() != null
// post: Trả về thông tin Tenant hợp lệ (code, name, colors, metadata)
// throws: TenantHeaderMissingException nếu tenantId null; TenantNotFoundException nếu không tìm thấy
```

## Interface: `GetStoresListUseCase`
```java
List<StoreSummaryResponse> execute(String keyword, FulfillmentType fulfillmentType, Double latitude, Double longitude, UUID currentUserId);
// pre: TenantContext.getTenantId() != null
// post: Trả về danh sách chi nhánh hoạt động. Nếu có lat/lng, tính khoảng cách Haversine (km) và sắp xếp tăng dần. Nếu có currentUserId, kiểm tra isFavorite.
// throws: TenantHeaderMissingException nếu tenantId null
```

## Interface: `GetStoreDetailUseCase`
```java
StoreDetailResponse execute(UUID storeId);
// pre: storeId != null; TenantContext.getTenantId() != null
// post: Trả về chi tiết Store kèm phí giao hàng, bán kính, giờ mở cửa
// throws: StoreNotFoundException nếu không tìm thấy store thuộc tenantId
```

## Interface: `GetStoreTablesUseCase`
```java
List<StoreTableResponse> execute(UUID storeId);
// pre: storeId != null; TenantContext.getTenantId() != null
// post: Trả về danh sách bàn ăn thuộc chi nhánh chỉ định
// throws: StoreNotFoundException nếu store không tồn tại
```

## Interface: `ResolveTableQrUseCase`
```java
ResolvedTableQrResponse execute(String qrToken);
// pre: qrToken non-blank; TenantContext.getTenantId() != null
// post: Trả về thông tin bàn ăn và chi nhánh sở hữu bàn
// throws: InvalidQrTokenException nếu không tìm thấy bàn hoặc bàn không thuộc tenant hiện tại
```

## Interface: `ToggleFavoriteStoreUseCase`
```java
ToggleFavoriteResponse execute(UUID storeId, UUID userId, boolean favorite);
// pre: storeId != null, userId != null, TenantContext.getTenantId() != null
// post: Thêm hoặc xóa bản ghi favorite store. Trả về storeId và trạng thái isFavorite mới.
// throws: StoreNotFoundException nếu store không tồn tại
```

## Interface: `GetFavoriteStoresUseCase`
```java
List<StoreSummaryResponse> execute(UUID userId, Double latitude, Double longitude);
// pre: userId != null, TenantContext.getTenantId() != null
// post: Trả về danh sách các store đã được user yêu thích
```

# 5. Target Architecture

```
HTTP Request (Client / Kiosk)
    │
    ▼
TenantInterceptor (Trích xuất X-Tenant-ID ➜ TenantContext)
    │
    ▼
Spring Security (Public endpoints vs Authenticated endpoints)
    │
    ▼
Presentation Layer (TenantController / StoreController)
    │ [Validate input @Valid, @NotNull]
    ▼
Application Layer (UseCases: GetStoresList, ResolveTableQr, etc.)
    │ [@Transactional(readOnly = true), Haversine GPS calc, IDOR checks]
    ▼
Domain Layer (Store, Table, Exceptions) ◄──► Infrastructure Layer (Repositories & JPA Entities)
    │
    ▼
PostgreSQL DB (stores, store_tables, customer_favorite_stores)
```

# 8. Task Specifications

### Task 1: Domain Models, Enums & Domain Exceptions
- **Scope:** `backend/src/main/java/com/ordera/modules/tenant/domain/`
- **Responsibilities:**
  - Định nghĩa enum `FulfillmentType` (`ALL`, `DINE_IN`, `TAKEAWAY`, `DELIVERY`).
  - Cập nhật POJO `Store`, `StoreTable`, `Tenant` đầy đủ các trường khớp với DB schema.
  - Tạo mới POJO `CustomerFavoriteStore`, `KioskDevice`.
  - Tạo các ngoại lệ miền: `StoreNotFoundException`, `TableNotFoundException`, `InvalidQrTokenException`, `TenantNotFoundException`, `TenantHeaderMissingException`.
- **Acceptance Criteria:**
  - Không chứa bất kỳ import nào từ `org.springframework.*` hay `jakarta.persistence.*`.

### Task 2: Repositories & MapStruct Mapper
- **Scope:** `backend/src/main/java/com/ordera/modules/tenant/infrastructure/`
- **Responsibilities:**
  - Tạo `CustomerFavoriteStoreRepository`, `KioskDeviceRepository`.
  - Bổ sung các phương thức truy vấn cho `StoreRepository` (`findByTenantIdAndActive`, tìm kiếm `keyword`, lọc theo hình thức nhận).
  - Bổ sung `findByTenantIdAndQrCodeToken` cho `StoreTableRepository`.
  - Tạo `TenantDtoMapper` ánh xạ Domain POJO <-> JPA Entity <-> DTO Response.

### Task 3: Request & Response DTOs
- **Scope:** `backend/src/main/java/com/ordera/modules/tenant/presentation/dto/`
- **Responsibilities:**
  - Tạo `TenantResponse`, `StoreSummaryResponse`, `StoreDetailResponse`, `StoreTableResponse`, `ResolvedTableQrResponse`, `ToggleFavoriteResponse`, `FulfillmentOptionsResponse`.
- **Acceptance Criteria:**
  - Đầy đủ các trường theo tài liệu API Design `01-tenant-and-store-api.md`.

### Task 4: 7 Use Cases Implementation
- **Scope:** `backend/src/main/java/com/ordera/modules/tenant/application/`
- **Responsibilities:**
  - Cài đặt 7 Use Case interfaces và 7 Use Case implementations:
    1. `GetTenantInfoUseCaseImpl`: Đọc thông tin Tenant theo context `TenantContext.getTenantId()`.
    2. `GetStoresListUseCaseImpl`: Lọc cửa hàng, tính khoảng cách Haversine GPS km (R=6371), làm tròn 2 chữ số thập phân, sắp xếp tăng dần theo khoảng cách.
    3. `GetStoreDetailUseCaseImpl`: Lấy chi tiết Store theo `storeId` và `tenantId`.
    4. `GetStoreTablesUseCaseImpl`: Lấy danh sách bàn theo `storeId` và `tenantId`.
    5. `ResolveTableQrUseCaseImpl`: Giải mã QR token thành thông tin bàn ăn và store.
    6. `ToggleFavoriteStoreUseCaseImpl`: Thêm hoặc xóa cửa hàng yêu thích của user.
    7. `GetFavoriteStoresUseCaseImpl`: Lấy danh sách chi nhánh yêu thích của user.
- **Acceptance Criteria:**
  - Mỗi class use case có annotation `@Service` và `@Transactional(readOnly = true)`.
  - Phương thức ghi dữ liệu có `@Transactional`.

### Task 5: Web Controllers & Exception Handling
- **Scope:** `backend/src/main/java/com/ordera/modules/tenant/presentation/`, `backend/src/main/java/com/ordera/common/exception/`, `backend/src/main/java/com/ordera/config/`
- **Responsibilities:**
  - Tạo `TenantController` với endpoint `GET /api/v1/tenants/current`.
  - Tạo `StoreController` với 6 endpoints chi nhánh, bàn, QR và yêu thích.
  - Cập nhật `GlobalExceptionHandler` bắt các domain exceptions và trả về RFC 7807 với error code (`TENANT_HEADER_MISSING`, `STORE_NOT_FOUND`, `TABLE_NOT_FOUND`, `INVALID_QR_TOKEN`, `TENANT_NOT_FOUND`, `UNAUTHORIZED`).
  - Cập nhật `SecurityConfig` cho phép `/api/v1/tenants/**`.

### Task 6: Unit Tests & WebMvc Tests Verification
- **Scope:** `backend/src/test/java/com/ordera/modules/tenant/`
- **Responsibilities:**
  - Viết unit tests cho UseCases theo chuẩn AAA (Arrange - Act - Assert).
  - Viết WebMvc tests cho Controllers sử dụng MockMvc.
  - Chạy `mvn test -f backend/pom.xml` đảm bảo 100% test pass.

# 9. Edge Cases

| Tình huống ngoại lệ | Xử lý | Handled In |
|---|---|---|
| Thiếu header `X-Tenant-ID` | Bắt tại UseCase/Controller, ném `TenantHeaderMissingException` ➜ trả 400 `TENANT_HEADER_MISSING` | Task 4, Task 5 |
| Header `X-Tenant-ID` là chuỗi không phải UUID | Interceptor bỏ qua ➜ Context null ➜ trả 400 `TENANT_HEADER_MISSING` | Task 5 |
| Quét QR token không tồn tại hoặc thuộc tenant khác | Ném `InvalidQrTokenException` ➜ trả 404 `INVALID_QR_TOKEN` | Task 4, Task 5 |
| `storeId` không thuộc về `tenantId` hiện tại (tấn công IDOR) | StoreRepository lọc kép `(id, tenant_id)`, không tìm thấy ➜ ném `StoreNotFoundException` 404 | Task 4 |
| Không truyền tọa độ GPS khi gọi danh sách cửa hàng | `distanceKm` trả về `null`, giữ nguyên thứ tự sắp xếp mặc định | Task 4 |
| Khách vãng lai gọi API danh sách cửa hàng | `isFavorite` mặc định là `false` | Task 4 |
| User chưa đăng nhập gọi toggle favorite | Bắt `user == null` ➜ trả 401 `UNAUTHORIZED` | Task 5 |

# 10. Risks & Mitigation

| Rủi ro | Mức độ | Biện pháp giảm thiểu |
|---|:---:|---|
| Sai số tính khoảng cách GPS | Thấp | Sử dụng chuẩn bán kính $R = 6371.0\text{ km}$, kiểm thử với tọa độ thực tế của Oslo |
| MapStruct compile error | Thấp | Cấu hình `@Mapper(componentModel = "spring", unmappedTargetPolicy = ReportingPolicy.IGNORE)` |
| Thiếu quyền truy cập Spring Security | Thấp | Thêm `/api/v1/tenants/**` vào danh sách `permitAll()` trong `SecurityConfig` |
